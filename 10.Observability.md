## 1. Scope

Learning-scale observability for 12 repos on AWS Free Plan ($200/6mo). No Prometheus/Grafana in v1 (traffic-scale). This doc owns logs/health/metrics/alarms/dashboards; `9.Testing.md` owns pre-deploy verification.

---

## 2. Logs

- pino JSON to stdout → Docker logs → CloudWatch Logs (one group per service).
- Every line carries `requestId` (`x-request-id` from Nginx), `service`, `level`, `durationMs` where relevant.
- Debug path: filter `requestId=<id>` across groups to trace checkout end-to-end.

---

## 3. Health + Metrics

- `GET /health` (liveness) + `/health/ready` (deps: DB/Redis/bus) per service → Compose `depends_on` + ALB checks.
- RED per service: rate (req/s), errors (5xx), duration (p50/p90/**p99** — SLOs in `9.Testing.md §2`).
- Transport: local — consumer lag via `kafka-consumer-groups.sh`; AWS — SQS `ApproximateAgeOfOldestMessage` / `ApproximateNumberOfMessagesVisible`, DLQ depth.

---

## 4. Alarms (CloudWatch)

| Alarm | Threshold (v1) |
|---|---|
| 5xx rate per service | >1% over 5 min |
| Checkout p99 / suggest p99 | breach of `9.Testing.md §2` SLOs |
| Queue age (SQS) / consumer lag (Kafka) | age >5 min / lag growing 10 min |
| DLQ depth | >0 for 5 min |
| RDS CPU / storage | >80% / <20% free |
| Credits | 50/25/10% remaining + 15/7/2-day expiry (AWS sends expiry mails) |

All alarms route to the alerter (§5). Dashboards: one CloudWatch dashboard (requests, p99, errors, queue age, DLQ, RDS) — screenshots deferred.

## 5. Alerting — Crash/Error to Phone (BASIC — detail later)

> TODO: full design deferred (watcher location, message templates, Terraform, BotFather/SNS setup, cost table, on-call runbook, self-test). Basic intent only below.

- **Purpose:** notify phone on DOWN / ERROR-burst / BACKLOG even when the app itself is down — watcher runs outside the 9 services.
- **Channels:** Telegram bot (all severities, free, instant) + SNS SMS (DOWN only, cost control). Email explicitly out of scope.
- **Signals:** `/health` 3 consecutive fails = DOWN; error-log burst (>5 errors/5min) = DEGRADED; DLQ depth >0 or queue age >5min = BACKLOG.
- **Dedupe:** one alert per incident + "recovered" message; 15-min cooldown; severity prefix (`🔴 DOWN` / `🟠 DEGRADED` / `🟡 BACKLOG`).
- **Next (deferred):** `ecom-infra/watcher/` implementation, secrets handling (never in git), runbook steps, staging self-test (kill a service → assert Telegram + SMS).
